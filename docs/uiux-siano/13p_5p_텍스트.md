# 13p · 5p 채울 텍스트

---

## 13p — 화면별 설계 의도 (4. 혜택 / 5. AI 챗봇)

11p·12p와 같은 양식입니다. 전부 코드에서 확인한 내용입니다.

### 4. 혜택

**핵심 의도**
흩어진 포인트·멤버십을 한 화면에 모으고, 이번 달 받은 혜택을 금액으로 확인.
Pull-to-Refresh로 최신 상태를 즉시 반영.

**화면 구성**

- 혜택 리포트 — 이번 달 총 혜택 금액과 최다 혜택 부문 요약
- 금융 포인트 — 등록 카드사의 포인트를 한 카드에 합산 표시
- 멤버십 — 등록한 멤버십을 3개씩 노출, '더보기'로 3개씩 추가
- 멤버십 '+ 추가' 버튼 — 이미 등록된 멤버십이 있을 때만 노출
- 단계별 Empty State — 카드 없음 / 포인트 없음 / 멤버십 없음을 각각 다른 문구와 버튼으로 안내
- 비로그인 시 로그인 유도 화면으로 전체 대체

**상호작용**

- 화면 최상단에서 아래로 당겨 새로고침 — 카드·포인트·멤버십·리포트를 한 번에 갱신
- 혜택 리포트 카드 터치 → 부문별 바텀시트
- 바텀시트에서 부문 선택 → 거래별 상세, '← 혜택 리포트'로 복귀
- 금융 포인트 카드 터치 → 포인트사별 상세 바텀시트
- 멤버십 카드 터치 → 멤버십 상세 (로고 · 가맹점 이용현황 · 연동 정보)
- 배경 터치로 바텀시트 닫기

**설계 노트 (넣으면 좋은 한 줄)**
리포트 카드와 바텀시트는 같은 API 응답을 나눠 쓴다. 따로 호출하면 그 사이 결제가 일어났을 때 합계와 상세가 어긋난다.

### 5. AI 챗봇

**핵심 의도**
자연어로 맞춤 금융 정보를 대화형으로 전달. 추천 질문으로 첫 대화의 문턱을 없앰.
수치는 추천 엔진이 계산하고 LLM은 문장으로 옮기는 역할만 한다. (4p 표기 원칙과 동일)

**화면 구성**

- 상단 헤더 'AI 금융 비서' + 뒤로가기
- 대화 영역 — 사용자 / AI 말풍선을 좌우로 구분
- 진입 시 인사 메시지 1건 자동 표시
- 추천 질문 칩 4종 — 추천 카드 알려줘 · 이번 달 소비 분석 · 혜택 리포트 · 카드 사용 내역
- 하단 입력창 + 전송 버튼

**상호작용**

- 추천 질문 칩 터치 → 입력창에 자동 입력 (바로 전송되지 않음 — 실수 방지)
- Enter 또는 전송 버튼으로 전송
- 응답 대기 중 '답변을 준비하고 있어요…' 표시, 입력창·전송 버튼을 비활성화해 중복 전송 차단
- 서버가 되물으면 그 맥락을 다음 질문에 실어 보내 앞 대화를 이어감
- 같은 내용이 연속으로 쌓이지 않도록 중복 메시지 제거

| 항목 | 초기 | 최종 | 바꾼 이유 |
|---|---|---|---|
| 프라이머리 | 그린 | 골드 | 화면 전반이 비슷한 초록으로 덮여 눌러야 할 곳이 드러나지 않음 |
| 그린의 역할 | 전역 강조 | 혜택 · 멤버십 | '좋은 일' 신호로 한정 |
| 버튼 | 그라디언트 | 단색 | 그라디언트는 명암비 측정이 안 됨 → 대비 계산이 가능해짐 |
| 버튼 텍스트 | 흰색 | #24242A | 골드 위 흰 글씨는 1.4:1 → 11.1:1 |
| 다크 강조색 | 브라운골드 | 쿨 그레이 | 노랑과 짝지으면 카카오 배색으로 읽힘 |

### 홈 · 결제 구조 변경 (와이어프레임과 대조해서 맞는 것만 남기기)

| 항목 | 와이어프레임 | 최종 | 바꾼 이유 |
|---|---|---|---|
| 홈 카드 노출 | 보유 카드 전체 나열 | 고정 카드 최대 3개 + 캐러셀 | 첫 화면에서 스크롤 없이 파악되게 |
| 홈 브리핑 위치 | 카드 목록 아래 | 상단 고정 | 로그인 직후 가장 먼저 읽히도록 |
| 결제 진입 순서 | 카드 먼저 선택 | 장소 먼저 선택 → 추천 | 추천의 근거가 되는 정보를 먼저 받음 |
| 결제 금액 입력 | 필수 | 선택 | 없어도 추천되고, 넣으면 정확해짐 — 진입 장벽 제거 |
| 결제 인증 | 별도 화면 이동 | 모달 | 결제 맥락을 끊지 않고 인증 |
